TokTok — instalação

Guia para quem compra o Goat Phone e vai ligar o TokTok completo. Para atualizar um servidor que já roda o celular, siga também toktok-upgrade.md.

Requisitos

ItemVersão / observação
FiveM (FXServer)artefato recente com Lua 5.4
oxmysqliniciado antes do goat-phone
MySQL ou MariaDBusuário com permissão de CREATE e ALTER
Node.js22 LTS, na mesma máquina do servidor (provedor de mídia local)
FrameworkvRP/Brasil, ESX, QB ou standalone (pela bridge do celular)

O provedor de mídia local (apps/media-local) recebe uploads, gera vídeos, faz o render do estúdio e a LIVE (mediasoup). Ele não precisa de Docker nem de FFmpeg instalado à parte: tudo vem do pnpm install.

1. Recurso do celular

  1. Copie a pasta goat-phone para resources/ (o nome da pasta precisa ser exatamente goat-phone).
  2. No server.cfg: 
    ensure oxmysql
ensure goat-phone
set goat_phone_media_secret "troque-por-um-segredo-longo-e-aleatorio"
  1. Inicie o servidor uma vez e confira no console as linhas [goat-phone] migration ... aplicada (17 na instalação limpa).

2. Provedor de mídia local

Na pasta apps/media-local do pacote:

pnpm install
pnpm start

Variáveis de ambiente (defina antes do pnpm start ou num gerenciador como PM2/NSSM):

VariávelPadrãoPara quê
MEDIA_SHARED_SECRET—obrigatória, igual ao goat_phone_media_secret
MEDIA_PUBLIC_URLhttp://127.0.0.1:4319URL que os jogadores usam para baixar vídeos; em produção use o IP público ou domínio
MEDIA_HOST / MEDIA_PORT127.0.0.1 / 4319onde a API escuta
MEDIA_DATA_DIR./dataonde os arquivos ficam guardados
MEDIA_LIVE_ANNOUNCED_ADDRESS—IP público anunciado para a LIVE (necessário fora da rede local)
MEDIA_LIVE_RTC_MIN_PORT / MEDIA_LIVE_RTC_MAX_PORT40000 / 40999portas UDP/TCP da LIVE; libere no firewall
MEDIA_LIVE_MAX_VIEWERS500espectadores por sala

No config.lua do servidor, Config.MediaLocalUrl aponta para a API (padrão http://127.0.0.1:4319).

Firewall: libere a porta HTTP de MEDIA_PUBLIC_URL e a faixa RTC da LIVE. A API (/uploads, /renders, /metrics) exige o segredo compartilhado; não exponha o segredo no cliente.

3. Ligar o TokTok

Em config.lua:

Config.TokTokEnabled = true

Reinicie (restart goat-phone). Com a flag desligada o app fica indisponível e as tabelas permanecem intactas.

4. Primeiros passos de administração

  1. Dê a permissão de administração (veja TokTok: administração).
  2. Abra /toktokadmin → Moedas e presentes: crie pacotes de moedas e presentes (o catálogo começa vazio).
  3. Catálogo: cadastre produtos e variantes com o nome do item do inventário do seu framework.
  4. Saúde: provedor de mídia "Disponível" e nenhuma operação incerta.

Configurações principais (config.lua)

ChavePara quê
Config.TokTokMonetizationvalor da moeda, taxa da plataforma, retenção, limite diário de presentes, preço da assinatura, regras de saque
Config.TokTokAdscusto por impressão, intervalo no feed, frequência, pacotes do Promover
Config.TokTokModerationstrikes, suspensão automática, links permitidos, anti-spam, prioridade por categoria de denúncia
Config.TokTokAdminPermissionspermissão do framework exigida por área do painel
Config.TokTokAccountRetentionMsprazo até a exclusão definitiva da conta (padrão 30 dias)
Config.TokTokRestrictedWordspalavras escondidas pelo modo restrito
Config.TokTokAdminCommandcomando do painel (padrão toktokadmin)
